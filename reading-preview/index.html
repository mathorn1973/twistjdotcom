TWIST-J

How much of physics can be read from an exact rule on integers?

Start with a fifth root of unity, j = exp(2πi/5). Add one to its square.

J=1+j2

Write a number in the basis (1, j, j², j³). Its four integer coefficients are enough to multiply it by J. Start with 1, written (1, 0, 0, 0). One step gives (1, 0, 1, 0). A second gives (0, −1, 1, −1). Each step can be undone exactly. The step and its inverse.

A physical model needs more. Which sites can interact? What survives the next interaction? What could an observer read twice? TWIST-J gives these questions separate mathematical statements, so each answer can be checked at its own scope.
