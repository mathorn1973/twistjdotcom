A number with four integer slots.

Choose j = exp(2πi/5), a fifth root of unity. A twist number is α = a + bj + cj² + dj³, with a, b, c, d integers.

a× 1
b× j
c× j²
d× j³

The relation j⁴ = −1 − j − j² − j³ folds higher powers back into those slots. The paper proves that the four coefficients are unique. “Four” describes the algebraic rank; it does not identify four spacetime axes.

Read the exact calculation

The current state is the seed.

Forward: compute t = a − c and u = b − c; output (t + d, u, a, u + d).

Inverse: for input (A, B, C, D), compute t = D − A, b = C + t, c = b − B, d = D − B; output (C, b, c, d).

Each schedule uses four integer additions or subtractions. This counts arithmetic operations, not bit cost: larger integers take more work.

Coefficients and norm use exact integer arithmetic. The norm is the determinant of multiplication by α. Numerical pictures use the bounded seed and the polar formula for Jⁿ, avoiding cancellation from large iterated coefficients. Values are rounded to six significant figures; they are illustrations, not error-certified measurements.

Forward: (1 − 0 + 0, 0 − 0, 1, 0 − 0 + 0). Inverse: (1, 1 + 0 − 1, 1 + 0 − 1 − 0, 0 − 0). Both are exact. The norm is 1 throughout.

The inverse already belongs to the ring.

The real golden unit is φ = −j² − j³, with φ² = φ + 1. In the first embedding it is the positive number (1 + √5)/2. It connects J to a root of unity:

φJ = jJ⁻¹ = −j − j²

So applying J⁻¹ requires no rounding and no fractions in the four coefficient slots. It undoes J for every twist number, including zero. A sample can illustrate that statement; the proof establishes it.

Shrinking is only half the picture.

The two views evaluate the same four integers with different images of j. The first uses j ↦ exp(2πi/5); the second uses j ↦ exp(4πi/5).

The quartic algebraic norm is N(α) = |σ₁(α)|² |σ₂(α)|². Since N(J) = 1, the exact norm remains the seed’s norm even as the two radii change. An arbitrary seed need not have norm 1.

On the full four-dimensional real representation, the two area factors multiply to φ⁻² φ² = 1. This explains determinant one. It does not say that the ordinary length of the coefficient tuple stays fixed.

An algebraic foundation.

The paper provides exact coordinates, arithmetic and an invertible linear step in the classical fifth cyclotomic ring. That is the algebraic contribution to TWIST-J.

A physical update law, clock, metric or measurement rule needs additional definitions and evidence. The four slots and the two pictures do not supply those choices.

Check your understanding: after five J steps, must you return to the seed?

No, unless the seed is zero. The first picture makes a full turn, but its radius is multiplied by φ⁻⁵. The ring identity is J⁵ = φ⁻⁵, not J⁵ = 1. For a nonzero seed, applying five inverse steps does recover the seed exactly.
