Returns on the lattice and torus

On the integer lattice, the J map never returns a nonzero point exactly. On a torus, points do return. The difference is what counts as the same place.

Choose what “equal” means.

The same integer matrix M acts on three different spaces. Changing the space changes which points are identified; it does not change the rule.

Integer latticeℤ⁴

Four integers. A return requires exactly the original vector.

Real spaceℝ⁴

Four real coordinates. Equality still means exact equality.

Four-torusℝ⁴ / ℤ⁴

Coordinates differing by any integer vector describe the same point.

For example, −2/11 and 9/11 represent the same first coordinate on a torus: they differ by one. This identification applies separately to all four coordinates.

The point returns. Its lift moves.

Take the rational vector x = (−2, 1, 2, 6)/11 in real space. A lift is one vector representing a torus point. Apply M twice and compare the exact vector with its coordinates modulo one.

This is the starting class. Its first coordinate can be written as −2/11 or 9/11.

The exact two-step calculation

(−2, 1, 2, 6)/11 → (2, −1, −2, 5)/11 → (9, 1, 2, 6)/11.

After two steps the lift has changed by (1, 0, 0, 0), an integer vector. Its torus class is back. After one step the residues differ, so the exact period is two.

Why the quotient counts these returns →

One view contracts. Another expands.

First complex plane× φ⁻¹

Scale ≈ 0.618, with a 72° rotation.

Second complex plane× φ

Scale ≈ 1.618, with a −36° rotation.

These are two views together giving real coordinates on the full four-dimensional space. Looking only through the first plane hides the expanding directions. The same evaluation is nevertheless injective on integer vectors: the hidden real plane contains no nonzero integer vector.

No eigenvalue has modulus one. Therefore Mⁿ − I is invertible for every positive n: a real vector cannot return exactly unless it is zero. On the torus, returning only up to an integer vector is enough.

What has been established?

The paper proves the all-period count by a quotient of integer lattices. The eight examples make it inspectable. The classical entropy theorem gives 2 log φ for this toral automorphism. Neither result computes the entropy of the native TWIST-J update U or identifies this four-torus with physical spacetime.

Check your understanding: do eleven fixed points of T² mean eleven two-cycles?

No. They include one fixed point of T. The remaining ten points form five two-cycles. “Fixed after n steps,” “exact period n,” and “number of n-cycles” count different things.
