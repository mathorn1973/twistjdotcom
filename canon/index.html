Status discipline

Every claim retains its declared label: T-LOCK / LOCK / T / D / C / H / O / F. No summary is stronger than its committed source. A fired falsifier remains part of the record.

Canon releases use integer numbers only: 1, 2, 3, and so on. The value cff-version: 1.2.0 identifies only the Citation File Format schema; the active citation version is version: "10".
