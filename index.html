TWIST-J

How much of physics can be read from an exact rule on integers?

Start with a fifth root of unity, j = exp(2πi/5). Add one to its square.

J=1+j2

Write a number in the basis (1, j, j², j³). Its four integer coefficients are enough to multiply it by J. Start with 1, written (1, 0, 0, 0). One step gives (1, 0, 1, 0). A second gives (0, −1, 1, −1). Each step uses four additions or subtractions and can be undone exactly. Kernel, matrix and inverse · Exact Python verifier.

From arithmetic to a physical reading

The programme separately declares an autonomous state with an unbounded counter and a finite checkpoint in F56. One exact map U advances the state. The declared architecture has no fitted dimensionless parameter and uses electron mass as its single SI calibration anchor.

The decoder starts with forward U-orbits and reads matter, then geometry, then clock. It is a typed partial interface whose outputs never feed back into the update. Its registered readings are dictionary entries. Any proposed family of readings must classify its alternatives, explain their overlaps and fix how to choose between them independently of the result it is meant to explain.
